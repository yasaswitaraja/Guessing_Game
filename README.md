# 🎯 Guess The Number Game

A simple and interactive web-based number guessing game built using Streamlit.

## 🚀 Live Demo
👉 https://guessinggame-09.streamlit.app/

##  How It Works
- The app randomly selects a number between 1 and 100
- You try to guess the number
- It gives hints:
  - 📉 Too low
  - 📈 Too high
- Tracks number of attempts
- 🎉 Shows success when you guess correctly

##  Tech Stack
- Python
- Streamlit

##  Run Locally

```bash
pip install streamlit
streamlit run app.py
